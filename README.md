# Webflix

Ouvre `index.html` (idéalement via un petit serveur local) :

1. Connexion (identifiant `yvanpirs`).
2. La vidéo YouTube se lance automatiquement (en muet, bouton « Activer le son »).
3. Après 15 min sur le site, la vidéo se met en pause et un pop-up « Cliquez pour continuer » apparaît.
4. Page de l’enveloppe pour Hanita, qui s’ouvre avec une animation et révèle la lettre.

Astuce test : ajoute `?test` à l’URL pour que le pop-up arrive après 10 secondes.

Le texte de la lettre se modifie dans `index.html`, dans `<article class="letter">`.
